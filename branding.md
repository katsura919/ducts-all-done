## Recommendations & Improvements

### Typography — Suggested Upgrade

The current heading font (Ubuntu) is functional but generic. For a home services company targeting homeowners, the hero text should feel **trustworthy, bold, and clean** — like a company that takes pride in their work.

#### Suggested Font Pairing

| Role            | Current      | Recommended      | Why |
|-----------------|--------------|------------------|-----|
| Hero H1         | Ubuntu       | **Montserrat**   | Bold, geometric, high authority — reads well at large sizes and signals professionalism |
| Subheading / H2 | Ubuntu       | **Montserrat**   | Keeps the pairing consistent, use SemiBold weight |
| Body / P        | Nunito Sans  | **Inter**        | More neutral and highly legible at small sizes; widely trusted in service-business UIs |

**Google Fonts import:**
```
Montserrat:wght@600;700;800
Inter:wght@400;500;600
```

#### Hero Text Style

| Property        | Suggested Value          | Reasoning |
|-----------------|--------------------------|-----------|
| Font            | Montserrat               | Strong, clean, trustworthy |
| Weight          | 800 (ExtraBold)          | Commands attention above the fold |
| Size (desktop)  | 56–64px                  | Current 35px is too small for a hero headline |
| Size (mobile)   | 36–40px                  | Readable on small screens |
| Line Height     | 1.1–1.15                 | Tight but not cramped for large display text |
| Letter Spacing  | -0.5px to -1px           | Slight negative tracking looks sharp at big sizes |
| Transform       | None (Title Case)        | All-caps feels aggressive for a residential service |
| Color           | `#FFFFFF` on dark bg OR `#152F45` on white | High contrast, on-brand |

#### Suggested Color Treatment for Hero

The navy `#152F45` primary is strong. For the hero section consider:
- **Dark hero:** `#152F45` background → white `#FFFFFF` headline → sky blue `#2EA3F2` accent word or CTA
- **Light hero:** White background → navy `#152F45` headline → sky blue `#2EA3F2` underline or highlight

#### Font Size Scale (Updated Recommendation)

| Element      | Current | Recommended |
|--------------|---------|-------------|
| Hero H1      | 35px    | 60px (desktop) / 38px (mobile) |
| H2           | 24px    | 32px |
| H3           | —       | 22px |
| Body         | 12px    | 16px (12px is too small for readability) |
| Small / Fine | —       | 13px |

> **Note:** 12px body text is below the recommended minimum (16px) for readability and accessibility (WCAG). This is a priority fix.
